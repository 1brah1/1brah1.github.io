Research

  • Hot/Cold Weight Swapping and KV-Cache Placement for LLM Inference on Wireless GPU Infrastructurein progress

    Final-year thesis · advised by Prof. Zili Meng · 2026–2027

    WiCi lets a mobile client run CUDA on a nearby GPU server over Wi-Fi. I'm designing the server-side memory policy for when the model and its KV cache exceed one H800's 80 GB: hot layers and live KV pages stay in VRAM, cold layers are prefetched from DRAM or NVMe while the current layer runs, and only tokens cross the wireless link.

    Target: decode at ≥ 80% of a fully VRAM-resident baseline, compared against FlexGen-style offload, measured as TTFT, p95 inter-token latency and tokens/s.

Selected projects

  • Real-Time Visual Question Answering for Low-Vision Navigation on a Jetson Orin NX

    COMP4901D course project, with Hashim · Mar – May 2026

    A camera, a Jetson and a small vision-language model (SigLIP + Qwen2.5-0.5B) that answer crossing, stairs and obstacle questions out loud. I built the vision encoder, token pooling, the evaluation framework and all on-device benchmarking, plus CUDA/PyBind11 kernels for preprocessing.

    Pooling image tokens 576 → 36 cut mean on-device latency from 747 to 346 ms (2.2×) while accuracy rose from 25% to 50%.

    write-up code CUDA extensions

  • SignalProof: Auditing Equity Backtests for Look-Ahead Leakage

    Independent project · Aug 2026

    A Hong Kong equity research lab that injects look-ahead leaks on purpose and audits every run with purged walk-forward validation, the Deflated Sharpe Ratio and the Probability of Backtest Overfitting. A local LLM writes the research memo from the metrics alone and never sees prices.

    Both injected leaks are flagged FAIL (PBO 0.90 and 0.66); the clean pipeline gets WARN rather than a false pass.

    code

  • Automating Air-Ventilation Compliance (PNAP APP-152) in Autodesk Revit

    LWK + Partners · Jun – Aug 2026

    A pyRevit extension (about 17,000 lines of Python) that runs Hong Kong's street-canyon and air-permeability checks on the live building model, including wind corridors that may bend by up to 15°, and draws the PASS/FAIL evidence into dedicated audit views.

    A typical run went from 10–30+ minutes to 30–90 seconds after I split the plane search into a cheap sweep and a full check on the best candidates.

    proprietary code

  • Retrieval-Augmented Generation on an 8 GB Laptop GPU

    Independent project · Jun 2026

    A RAG pipeline sized for an RTX 4060: embeddings run on the CPU so the full 8 GB goes to the language model, with one switch between a local 4-bit model and NVIDIA's hosted NIM behind the same response schema.

    Over 10 runs: 14.94 tokens/s locally vs 33.66 tokens/s on NIM (0.771 s to first token).

    code

  • Signed Area: Linear Algebra as a Scroll-Driven Story

    Independent project · Jul 2026

    One Canvas 2D scene in which the same particles move through orientation tests, convex hulls, SVD, PCA and softmax attention as you scroll. All of the math is implemented by hand (no Three.js) and unit-tested with Vitest.

    live demo code

  • Smart Recycling Station on an STM32
